# <img src="assets/icons/template.svg" width="40" align="center"> Discloud Templates

Welcome to the official **Discloud Templates** repository.

This repository brings together templates designed to simplify the creation, configuration, and deployment of applications on Discloud. Each template is organized to provide a consistent structure, clear documentation, and a straightforward experience from installation to deployment.

## <img src="assets/icons/categories.svg" width="40" align="center"> Categories

The templates are organized into different categories, including:

* Bots;
* Web Applications;
* APIs and Microservices;
* Tools and Utilities;
* Open Source Projects.

## <img src="assets/icons/file.svg" width="40" align="center"> What does each template include?

Each template may include:

* A complete **README.md** with installation, configuration, and usage instructions.
* Images, banners, and screenshots to complement the documentation.
* A well-organized file and directory structure.
* A deployment guide for Discloud.
* Information about dependencies, requirements, and environment variables.
* Development recommendations and best practices.

## <img src="assets/icons/target.svg" width="40" align="center"> Objective

Provide a modern, organized, and well-documented template library, enabling developers to start new projects quickly, maintain a high standard of quality, and find everything they need in one place.
