# <img src="assets/icons/template.svg" width="40" align="center"> Discloud Templates

Bem-vindo ao repositório oficial dos **Templates da Discloud**.

Este repositório reúne templates desenvolvidos para facilitar a criação, configuração e implantação de aplicações na Discloud. Cada template é organizado para oferecer uma estrutura consistente, documentação clara e uma experiência simples desde a instalação até o deploy.

## <img src="assets/icons/categories.svg" width="40" align="center"> Categorias

Os templates estão organizados em diferentes categorias, incluindo:

- Bots;
- Aplicações Web;
- APIs e microsserviços;
- Ferramentas e utilitários;
- Projetos Open Source.

## <img src="assets/icons/file.svg" width="40" align="center"> O que acompanha cada template?

Cada template pode incluir:

- Um **README.md** completo com instruções de instalação, configuração e utilização.
- Imagens, banners e capturas de tela para complementar a documentação.
- Estrutura organizada de arquivos e diretórios.
- Guia de deploy na Discloud.
- Informações sobre dependências, requisitos e variáveis de ambiente.
- Recomendações e boas práticas para desenvolvimento.

## <img src="assets/icons/target.svg" width="40" align="center"> Objetivo

Disponibilizar uma biblioteca de templates moderna, organizada e bem documentada, permitindo que desenvolvedores iniciem novos projetos com rapidez, mantenham um padrão de qualidade e encontrem tudo o que precisam em um único lugar.
